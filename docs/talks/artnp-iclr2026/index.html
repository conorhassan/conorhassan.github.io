Meta-Learning

Let \(\mathcal{D} = \{(x_n, y_n)\}_{n=1}^N\) be a dataset of input-output pairs.

Standard Prediction

Train on \(\mathcal{D}\) to learn fixed parameters \(\theta\).

\[p_\theta(y^\star \mid x^\star)\]

New dataset = retrain from scratch.

Probabilistic Meta-Learning

Train on a distribution of datasets \(p(\mathcal{D})\). Condition on \(\mathcal{D}\) at test time.

\[p_\theta(y^\star \mid x^\star; \mathcal{D})\]

Adapts predictions to different datasets without retraining.

Transformer Probabilistic Models

Transformer Neural Processes (TNPs) and Prior-Fitted Networks (PFNs) predict targets conditioned on context:

\[p_\theta(y^\star_{1:M} \mid x^\star_{1:M};\, \mathcal{D}) = \prod_{m} p_\theta\bigl(y^\star_m \mid x^\star_m;\, \mathcal{D}\bigr)\]

Targets are predicted independently — no dependencies between \(y^\star_m\).

Garnelo+ 2018, Nguyen & Grover 2022, Müller+ 2022, Hollmann+ 2023, Hollmann+ 2025, Qu+ 2025

2/14

Current Parameterization

Under the hood, a transformer encodes context and predicts targets via attention:

\[p_\theta(y^\star_m \mid x^\star_m;\, \mathcal{D}) = p_\theta\bigl(y^\star_m \mid \text{CrossAttn}(x^\star_m, \text{SelfAttn}(\mathcal{D}))\bigr)\]
Encode Context
Bidirectional self-attention over \(\mathcal{D}\)
Predict Targets
Cross-attention from \(x^\star\) to \(\mathcal{D}\)
3/14

Attention Basics

Attention lets queries (targets) retrieve information from keys and values (context).

Self-Attention

All \(N\) tokens attend to each other. \(\mathcal{O}(N^2)\)

Cross-Attention

One target queries \(N\) context tokens. \(\mathcal{O}(N)\)

Cross-attention is \(N\times\) more efficient for single-target prediction.

4/14

Bottleneck

To model joint distributions, we need autoregressive factorization:

\[p_\theta(y^\star_{1:K} \mid x^\star_{1:K}; \mathcal{D}) = \prod_{k=1}^{K} p_\theta\left(y^\star_k \mid x^\star_k;\, \mathcal{D} \cup \{(x^\star_j, y^\star_j)\}_{j=1}^{k-1}\right)\]

Each step requires re-encoding \(\mathcal{D} \cup \{\text{previous predictions}\}\) via bidirectional self-attention.

Cost to generate sample from \(K\)-dimensional joint: \(\mathcal{O}(K(N+K)^2)\)

5/14

KV Caching for LLMs

1. Encode prompt via self-attention → cache \(K, V\)

2. New token cross-attends to cached \(K, V\)

3. Append new token's \(K, V\) to cache

4. Repeat. Cost per token: \(\mathcal{O}(N)\) not \(\mathcal{O}(N^2)\)

Key requirement: Tokens form a causal sequence — each token sees only previous tokens. Our parameterization doesn't have this structure.
6/14

Causal Autoregressive Buffer

Context \(\mathcal{D}\) is immutable. Buffer \(\mathcal{B}\) grows causally with predictions.

\[p_\theta(y^\star_{1:K} \mid x^\star_{1:K}; \mathcal{D}) = \prod_{k=1}^{K} p_\theta\left(y^\star_k \mid x^\star_k;\, [\mathcal{D}, \mathbf{b}_{1:k-1}]\right)\]
Context
Encoded once, cached, read-only
Buffer
Causal, grows with each prediction

\(\mathcal{O}(K(N+K)^2) \to\) \(\mathcal{O}(N^2 + NK + K^2)\)

In-Context Multi-Objective Optimization

Xinyu Zhang, Conor Hassan, Julien Martinelli, Daolang Huang, Samuel Kaski

Black-Box Optimization

Let \(\mathcal{X}\) be a design space and \(f\) an objective function. We seek \(\mathbf{x} = \arg\max_{\mathbf{x} \in \mathcal{X}} f(\mathbf{x})\)

Challenge

No information about \(f\) — gradients, convexity, invariances...

Can only evaluate \(y_i = f(\mathbf{x}_i) + \varepsilon\)

Collect observations \(\mathcal{D}_t = \{(\mathbf{x}_i, y_i)\}_{i=1}^t\)

Bayesian Optimization

Surrogate: \(f(\mathbf{x}) \sim \mathcal{GP}(\mu_{\theta_1}(\mathbf{x}), k_{\theta_2}(\mathbf{x}, \mathbf{x}'))\)

Acquisition: \(\mathbf{x}_{t+1} = \arg\max_{\mathbf{x}} \alpha_{\theta_3}(\mathbf{x} \mid \mathcal{D}_t)\)

Evaluate, append, update surrogate, repeat.

1/16

Multi-Objective Optimization

We now observe a vector of objectives \(\mathbf{f}(\mathbf{x}) = [f_1(\mathbf{x}), \dots, f_M(\mathbf{x})] \in \mathbb{R}^M\)

Pareto optimality: \(\mathbf{x}\) dominates \(\mathbf{x}'\) if

\(\forall i:\; f_i(\mathbf{x}) \ge f_i(\mathbf{x}')\) and \(\exists i:\; f_i(\mathbf{x}) > f_i(\mathbf{x}')\)

Hypervolume indicator:

\[\mathrm{HV}(\mathcal{P};\, \mathbf{r}) = \mathrm{Vol}\!\left(\left\{\mathbf{y} \in \mathbb{R}^m : \exists\, \mathbf{p} \in \mathcal{P},\; r_i \leq y_i \leq p_i \;\;\forall\, i\right\}\right)\]

Volume dominated by \(\mathcal{P}\), bounded by \(\mathbf{r}\).

2/16

Caveats

1. Surrogate/acquisition selection dependent on expert choice; won't transfer. → "Learn" the language of optimization
2. Slow in high-throughput settings due to GP cubic complexity. → Offline pre-training, reduce inference to a feedforward pass
3. Most methods are myopic, focused on 1-step optimality. → Train over long optimization horizons using RL
4. Learning from previous campaigns not straightforward — different objectives or dimensions. → Dimension-agnostic task embeddings

Solution: Task-Agnostic Amortization (TAMO)

TAMO: Architecture at a Glance

Optimization ⟺ Predicting the optimum. Same core components for both prediction and optimization batches.

1. Dimension-agnostic embedder: scalar→vector maps, tokens independent of input/output dim.
2. Transformer encoder: aggregates variable-size histories/contexts into compact summary.
3. Task conditioning: learned tokens injected late to specialize computation.
4. Two heads: prediction (density) and policy (acquisition over query set).
